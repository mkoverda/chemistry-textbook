# Учебник по общей химии

Это небольшой проект, посвящённый созданию учебника по общей химии в авторском изложении. Учебник рассчитан на начинающих и создаётся при помощи LaTeX. Учебник пока неполный.

## Сборка

Просто скачайте архив с одним из релизов или файлами проекта и выполните в его корне:

```bash
latexmk
```

Параметры сборки лежат в `latexmkrc`, поэтому дополнительных ключей не нужно. Готовый `main.pdf` появится в корне проекта, все вспомогательные файлы — в `build/`. Чтобы пересобирать документ при каждом сохранении, запустите `latexmk -pvc`, а чтобы убрать всё сгенерированное — `latexmk -C`.

Обратите внимание, что в рабочей версии могут быть проблемы с форматированием и недоработанные разделы.
