# Учебник по общей химии

Это небольшой проект, посвящённый созданию учебника по общей химии в авторском изложении. Учебник рассчитан на начинающих и создаётся при помощи LaTeX. Учебник пока неполный.

## Сборка

Просто скачайте архив с одним из релизов или файлами проекта и выполните в его корне:

```bash
latexmk
```

Параметры сборки лежат в файле `latexmkrc`, поэтому дополнительных ключей указывать не нужно. Готовый PDF-файл `main.pdf` появится в корне проекта, а все вспомогательные файлы, созданные при сборке, — в `build/`. Чтобы пересобирать документ при каждом сохранении, запустите `latexmk -pvc`, а чтобы убрать всё сгенерированное, — `latexmk -C`.

Обратите внимание, что в рабочей версии проекта могут быть проблемы с форматированием и недоработанные разделы.

## Как редактировать материал

Структура кода LaTeX и принятые договорённости по оформлению материала выложены [здесь](https://chemistry.org.ru/contributing.html).

## Проверки исходников

В корне лежит скрипт `check.py`, предназначенный для проверки оформления, ссылок, указателя и пр., сфокусированный на тех проблемах, которые компилятор LaTeX отобразить не может. Рекомендуется запускать его после значительной правки материала. Ключи запуска следующие:

```bash
./check.py             # все проверки, полный отчёт
./check.py -q          # только найденные проблемы
./check.py --list      # перечень проверок
./check.py --only B2   # выполнить одну
```

Проверки по журналу сборки работают, только если в `build/` лежит файл `main.log` от завершившейся сборки; без него они просто пропускаются.
